# Chapter 2 – Introduction to scientific programming

The short examples of Chapter 2 of the *Radiation Detection Activity Book*. Each file name starts with the number of
the section in which the example is explained.

| Example | Book section | Expected output |
|---|---|---|

| `2.5_loops_and_decisions.py` | Section 2.5 | `expected_output/2.5_output.txt` |
| `2.6_functions.py` | Section 2.6 | `expected_output/2.6_output.txt` |

| `2.11_error_demo.py` | Section 2.11 | `expected_output/2.11_output.txt` |

`absorber.csv` is the small data file used by examples 2.8, 2.9 and 2.10. Keep it in the same folder as the scripts.
Example 2.11 stops with an error message on purpose: Section 2.11 explains how to read it.

**Run an example:** open it in Thonny and press **Run** (F5), or type `python 2.3_first_steps.py` in a terminal
opened in this folder.
