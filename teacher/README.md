# Teacher folder

`make_example_data.py` makes the **simulated** example data of every activity (fixed random seed 2026, so the
files are always the same). Change the model parameters in the script to make fresh practice data, then run it from
this folder: `python make_example_data.py`. It writes one CSV file into each activity folder and overwrites the
example files there.
